# searchx

Thin pointer to the shared implementation.

**Real location:** `~/.agents/tools/searchx/`

Commands:
- `searchx auth login`
- `searchx search "..."`

Searches public X content through SpaceXAI. It does not read the user's personalised Home or Following timeline.

See the main README for full instructions.
