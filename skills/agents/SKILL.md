# xsearch

This skill points to the canonical, agent-agnostic implementation.

**Location:** `~/.agents/tools/xai-xsearch/`

Use `xsearch search "..."` for public X searches and `xsearch auth login` when OAuth setup is needed. It does not read the user's personalised Home or Following timeline.
