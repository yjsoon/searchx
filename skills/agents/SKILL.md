# searchx

This skill points to the canonical, agent-agnostic implementation.

**Location:** `~/.agents/tools/searchx/`

Use `searchx search "..."` for public X searches and `searchx auth login` when OAuth setup is needed. It does not read the user's personalised Home or Following timeline.
